# Profile artwork

Original SVG artwork for this profile, generated by `scripts/render_profile_assets.py` using only the Python standard library.

To edit the design or text, update the generator and run:

```sh
python3 scripts/render_profile_assets.py
git diff --check
```

The header has desktop and mobile variants for light and dark themes, selected by the README's `<picture>` element. Project images have fixed high-contrast palettes and wrap onto separate lines in narrow layouts. All images include descriptive alt text in the README. Keep project names, descriptions, and links accessible there when changing artwork.

These are local assets with no remote fonts, tracking, animation, live counters, or third-party image-generation endpoints. Keep detailed results and dated contribution evidence in `RESEARCH_EVIDENCE.md` and the linked case studies.
